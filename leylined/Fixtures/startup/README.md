# Startup fixtures

`bootstrap-worlds.json` supplies six- and twenty-window seed results to blocked
fake observation workers. These rows represent work held at an injected capture
boundary; the self-test never enumerates windows or creates AX observers, event
taps, AppKit renderers, or resident controls.

The empty complete result is a measured zero-window inventory. The incomplete
result has explicit failed completeness and must retain different readiness from
that measured empty result. The pre-capture pending state is generated by the
production startup coordinator and carries null windows and a null count.
